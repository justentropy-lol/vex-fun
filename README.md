# VEX

[Visit vex.fun](https://vex.fun/) · [Enter VORTEX](https://vortex.haus/)

VEX is a website for the VORTEX acolytes to shape together: its content,
its appearance, and what it becomes over time.

Acolytes choose a part of the site and propose a focused change through
VORTEX. A local AI builder applies those requests one at a time, turning
their descriptions into working pages. Each revision becomes the starting
point for the next.

The aim is to show what happens inside VORTEX and why it is worth paying
attention to. The site is an evolving experiment in collective authorship.

Built with static HTML and Tailwind CSS. This repository holds the website
source; participation happens through VORTEX.
